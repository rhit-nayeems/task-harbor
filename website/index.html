TASKHARBOR

Run coding tasks.
Review the evidence.

An open-source CLI for running Claude Code or Codex through planning, implementation, and verification.

Install

python -m pip install task-harbor

Python 3.11+ · Git · Authenticated Claude Code or Codex

Next, open a terminal in your project and run task-harbor check.

Find setup gaps before starting. No model calls; no project commands executed. First-run guide

The workflow

From a Markdown backlog
to a local integration branch.

Each task gets a separate Git worktree. Your configured tests run before model QA. Review the full diff and check results before accepting the work.

Task state is saved so you can stop and resume. Harbor doesn’t automatically push or merge into your original branch.
