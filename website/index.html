A FEW THINGS TO KNOW
Does Task Harbor replace Claude Code or Codex?+

No. It orchestrates their existing CLIs. You need one installed and authenticated. Harbor adds planning, task state, verification, and evidence around the agent.

Does my code stay on my machine?+

Harbor stores worktrees and run records locally. Your chosen agent can send repository context to its model provider under that provider’s settings and terms. Harbor is not an offline model.

Will it push or merge into my main branch?+

Harbor integrates checked tasks into a separate local branch. It does not automatically push changes or merge into your original branch. Review the integration branch before accepting it.

Can I use it on Windows, macOS, or Linux?+

The package requires Python 3.11+, Git, and a supported agent CLI. Automated tests run on Windows and Linux. macOS is not currently part of the CI test matrix. See the setup guide for terminal PATH troubleshooting.
